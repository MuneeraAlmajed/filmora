# FilmOra 🎞️
A ***personal watchlist-site*** where users can **A**dd, **E**dit, **U**pdate, and **D**elete a movie. User can also add *Rating* and *Status*.

## User Stories
-  As a user, I want to able to create an account
- As a user, I want to able to log on to my account 
- As a user, I want to able to log out from my account 
- As a user, I should be able to add a movie to my collection
- As a user, I should able to view my movies collections
- As a user, I should able to edit the movie, status, rating and other informations
- As a user, I should be able to delete movies from my movie collection
- As a user, I want to rate a movie so that I can record my opinion of it
- As a user, I want to mark the status of the movie: *Watched*,*To watch later*, *Not yet*.
- As a user, I want to see my watched and unwatched movies separately so that I can manage my watchlist.
- As a user, I want to search for a movie by title so that I can quickly find it.
