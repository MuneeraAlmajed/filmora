# FilmOra 🎞️
A ***personal watchlist-site*** where users can **A**dd, **E**dit, **U**pdate, and **D**elete a movie. User can also add *Rating* and *Status*.

## User Stories
1. As a user, I want to able to create an account
2. As a user, I want to able to log on to my account 
3. As a user, I want to able to log out from my account 

4. As a user, I should be able to add a movie to my collection
5. As a user, I should able to view my movies collections
6. As a user, I should able to edit the movie, status, rating and other informations
7. As a user, I should be able to delete movies from my movie collection

8. As a user, I want to rate a movie so that I can record my opinion of it
